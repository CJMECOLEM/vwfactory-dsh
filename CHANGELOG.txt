vwFactory 更新日志
==================

v0.4.6
  - 修复: 设置页显示英文「encrypted」，改为「Key 已加密」

v0.4.5
  - 新模型自动检测图片支持: Factory 上新的开源模型，插件启动时会发一张测试图自动检测能不能看图，
    结果记住不重复测；检测完重启 DSH 后，能看图的模型就可以直接发图片

v0.4.4
  - 在线更新: DSH 设置 -> Factory 账号 -> 插件版本，自动检查 GitHub 上的新版本，点「更新」即可
      * 下载后核对大小和 SHA-256，校验不通过不会安装
      * 旧版本自动备份，出问题可一键「回滚」
      * 更新后完全退出并重新打开 DSH 生效
      * 需要重新运行安装程序的版本会提示去下载页
  - 注意: 从 v0.4.3 及更早版本升级到 v0.4.4 需要手动安装一次，之后就能在线更新

v0.4.3
  - Key 加密保存: secrets.json 改用 Windows DPAPI 按当前用户加密，只有你的 Windows 账户能解开
      * 旧的明文文件首次启动自动迁移，备份 (*.bak) 一并加密，数据目录里不再有明文 key
      * 解不开时 (换电脑 / 换用户) 原文件原样保留，不会被覆盖；设置页提示
      * 系统禁止加密时退回明文保存并提示，不会丢 key；VWFACTORY_PLAIN_SECRETS=1 可关闭加密
  - 设置页显示「Key 已加密」

v0.4.2
  - 修复: DSH 里给 Claude / GPT 等模型发图片时提示「当前模型不支持图片」
      * Claude、GPT 全系声明支持图片
      * 开源模型按实测声明: glm-5.3-flash、kimi-k3、DeepSeek V4 系列、minimax-m3、minimax-m2.7 支持；
        glm-5.3、nemotron-3-ultra (网关拒绝) 和 minimax-m2.5 (图片被丢弃) 保持纯文本

v0.4.1
  - 数据文件改为安全写入 (先写临时文件再替换)：账号、key、本机令牌、cordis.patch.yml
    写到一半崩溃或断电也不会损坏 (实测强杀 40 次: 旧写法损坏 2 次，新写法 0 次)
  - 自动备份: key 文件每次保存前备份，账号文件启动时及每 10 分钟备份 (*.bak)
  - 自动恢复: 文件损坏或丢失时从备份恢复，损坏的文件另存为 *.corrupt-时间 不会被覆盖，
    设置页会显示提示

v0.4.0
  - 多账号均衡 (设置 -> Factory 账号 -> 分配方式，默认仍是「单账号」):
      * 每个对话固定在一个账号上 (按会话指纹识别)，保证缓存命中；空闲 60 分钟后释放
      * 新对话分给主额度剩余最多的账号 (同时考虑进行中的请求和对话数)
      * 账号主额度到 90% 或出错冷却时，对话在下一轮自动迁到更健康的账号；
        所有账号都 >=90% 时不来回切换
      * 出错换号只改变该对话的账号，不影响其它对话
  - 额度提醒: 主额度到 75% / 90% / 用完时各提醒一次，恢复后提示；自动切号也会提示
  - 使用期间后台每 5 分钟刷新额度 (提醒和均衡都依赖它)，请求后也会顺带刷新
  - 输入框胶囊 / 弹窗 / 设置页显示分配方式、各账号对话数和冷却状态
v0.3.0
  - 客户端版本号更新到 0.238.0，并会自动跟随 Factory 官方最新版本 (每 6 小时检查，只升不降)
  - 同一对话使用固定的会话 ID (之前每个请求随机)，与官方 Droid 行为一致，利于服务端缓存与会话亲和；
    GPT (Responses) 请求自动带上 prompt_cache_key
  - Claude 5.x 直接发送 adaptive 思考参数，不再先报 400 再重试；修正思考预算到强度的映射
  - 自动切号增强:
      * 出错时依次尝试所有账号 (之前只试一个)
      * 出错账号进入冷却: 401/403 冷却 30 分钟，402 冷却 6 小时，
        429 冷却到对应额度窗口重置 (未知时按 Retry-After，30 秒~30 分钟)
      * 请求前若当前账号在冷却中或标准额度已用满，先切到可用账号
  - 额度显示更稳: 窗口重置后自动归零；兼容 secondsRemaining / notAvailable；
    查询失败时保留上次数据
  - Anthropic 请求在客户端未设置时自动加缓存标记 (DSH 自身已会加，主要惠及外部客户端)

v0.2.0
  - 一键安装 / 更新脚本 (自动识别版本、可自动重启 DSH、托管配置段自动刷新)
  - 输入框下方额度胶囊 (仅 Factory 模型时显示)、右侧栏「Factory 额度」

v0.1.0
  - 首个版本: 多账号管理、本机代理、设置页「Factory 账号」
